# SQL Projects

A collection of guided, tutorial-based SQL projects, built as part of my data engineering learning journey, following @datawithbaraa's SQL course series.

## Projects

- **[data_warehouse_project](./data_warehouse_project)** : A full ETL pipeline using the Medallion Architecture (Bronze, Silver, Gold), consolidating CRM and ERP source data into a business-ready star schema.
- **[data_analytics_project](./data_analytics_project)** : Exploratory and advanced SQL analytics built on top of the Gold layer, covering trends, rankings, segmentation, and reporting.

## Dataset

Sample CRM and ERP CSV data, provided as part of the course material.
